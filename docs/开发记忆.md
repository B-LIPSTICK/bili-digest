## 调试经验（同类问题再犯时直接复用）

- **多 P 合集「切了还是 P1」**：症状是 URL 有 `p=2`、状态栏显示已加载但内容不变。根因涉及 cid 解析链路：最终方案是 content 侧从 `__INITIAL_STATE__`（`videoData.cid` / `state.cid` / `pages[].cid`）+ 后台 view 接口按 p 参数解析兜底；曾用临时诊断日志（`console.log`）定位，修复后关闭。刷新无效是因为切换 P 不触发重新解析。
- **白屏/顶部导航消失**：Vue SSR hydration 冲突，内容脚本禁止插节点（已固化到 AGENTS.md）。
- **SW 动态 import 报错**：`import() is disallowed on ServiceWorkerGlobalScope` → 纯 JS MD5 重写。
- **字幕轨道切换不过来**：轨道列表来自 `x/player/wbi/v2`，缓存需按轨道语言隔离。

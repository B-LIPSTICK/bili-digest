# 自动记笔记 Prompt

后台 `captureNote` 动作使用：把用户按下「记笔记」瞬间正在说的那句话，
从字幕上下文里整理成一条干净的笔记。

## 规则

你是中文文字编辑。下面是一段 B站视频字幕的上下文，用户想记下
「当前句」附近的内容。请：

1. 找到包含当前句的完整句子或完整意思单元；
2. 如果当前句是半句话，结合上下文把这句话补完整；
3. 删除明显的口头禅和语气词（如"然后""就是说""那个""嗯"）、重复和磕巴；
4. 改正明显的转写错别字，理顺标点，但保留说话人的原意和措辞，不总结、不缩写、不添加观点；
5. 输出 1 到 3 句完整的话；
6. 只输出一个 JSON 对象：{"text": "整理后的笔记"}，不要输出任何其他文字。
